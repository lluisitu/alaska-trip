About that button. It re-reads what GitHub has actually published and re-points every link at that exact build, so you never open a stale cached copy. It cannot start a rebuild — that needs a write token, and a token on a public page is a token anyone can use. Publishing is still ./publish.sh in ~/alaska-repo; Pages rebuilds by itself about a minute later, and this button is how you tell that it has.
